# موح الفاشل 3D — مشروع Godot 4

مشروع لعبة تصويب وبقاء ثلاثية الأبعاد بمنظور الشخص الثالث، مع إعدادات خفيفة للأجهزة المحمولة.

## ما يتضمنه النموذج الحالي
- ساحة حضرية تجريبية مع طريق ومبانٍ وحواجز.
- لاعب بمنظور الشخص الثالث وشخصية ثلاثية الأبعاد مبنية من أشكال Godot.
- 10 خصوم آليين يتحركون ويهاجمون اللاعب.
- إطلاق نار بالتصويب الشعاعي، ذخيرة ومخزن احتياطي وإعادة تلقيم.
- شريط صحة وعداد إقصاءات.
- أزرار لمس للحركة والقفز والإطلاق وإعادة التلقيم والعلاج.
- تحريك الكاميرا بالسحب على يمين الشاشة.
- إعداد عرض GL Compatibility لتوافق أوسع مع Android.

## التشغيل على Android
1. ثبّت Godot 4.3 أو أحدث على جهاز تطوير متوافق.
2. افتح مجلد `godot` كمشروع Godot.
3. اختبر المشهد الرئيسي داخل المحرر.
4. لتصدير APK يلزم تثبيت Android build template وإعداد Android SDK/JDK وفق وثائق Godot الرسمية.

## ملاحظة صريحة
هذه نسخة أولية قابلة للتطوير والاختبار وليست لعبة تجارية مكتملة أو بمستوى Apex Legends. لا تحتوي على لعب جماعي عبر الإنترنت أو نماذج شخصيات احترافية أو خريطة Battle Royale ضخمة. يلزم اختبارها على جهاز Android وإصلاح أي أخطاء قبل توزيع APK.
