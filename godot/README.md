# موح الفاشل — Godot 4

هذه بداية إعادة بناء اللعبة كمشروع ثلاثي الأبعاد مستقل بمحرك Godot 4.

## المرحلة الحالية
- ساحة اختبار ثلاثية الأبعاد.
- لاعب بمنظور الشخص الثالث.
- حركة WASD والأسهم، قفز بالمسافة، وتحريك الكاميرا بالماوس.
- إعداد عرض متوافق مع أجهزة الهاتف عبر GL Compatibility.

## التشغيل
1. ثبّت Godot 4.3 أو أحدث.
2. افتح مجلد `godot` من مدير المشاريع.
3. شغّل المشهد الرئيسي.

هذه نسخة تأسيسية وليست بعد لعبة Battle Royale مكتملة. الخطوات التالية: أزرار لمس للهاتف، شخصية بشرية برسوم متحركة، سلاح وإطلاق، أعداء، ثم لوبي وخريطة أكبر.
